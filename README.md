# 🧠 Brain IQ 100 — Number Puzzle Game

### Think Smart. Move Strategically. Train Your Brain.

🔗 **Live Demo:** https://brainiqtester.vercel.app/

Brain IQ 100 is an interactive number-arrangement puzzle game designed to challenge logical thinking, concentration, and problem-solving skills. The goal is to arrange numbers from **1 to 100 in the correct order** while completing the puzzle in as few moves as possible.

The game provides an engaging way to practice number recognition, planning, and strategic thinking through an interactive web interface.

## ✨ Features

- 🔢 **100-Number Puzzle:** Arrange numbers from 1 to 100 in the correct sequence.
- 🎮 **Multiple Game Modes:** Select from the available game modes.
- 🎯 **Difficulty Selection:** Choose a difficulty level to customize your challenge.
- 🔀 **Random Puzzle:** Start a randomly arranged puzzle.
- 📅 **Daily Challenge:** Take on the daily puzzle challenge.
- ⏱️ **Timer:** Track the time taken to complete a puzzle.
- 🏆 **Score Tracking:** Monitor your score and game progress.
- 🔄 **Undo and Redo:** Review and reverse moves using the available controls.
- 💡 **Hint System:** Get help when you need guidance.
- ⏸️ **Pause and Resume:** Pause the game and continue later.
- 🔁 **Restart and New Puzzle:** Restart your current game or begin another puzzle.
- ✅ **Correct Number Tracking:** Track correctly arranged and remaining numbers.
- 🌓 **Theme Toggle:** Switch between the available visual themes.
- 🔊 **Sound Controls:** Enable or disable game sound.
- 📱 **Interactive Interface:** Play directly through your web browser.

## 🎯 Objective of the Game

The main objective is to arrange the numbers from **1 to 100** in ascending order, following the game's rules.

Your goal is to:

1. Start a new or random puzzle.
2. Examine the current number arrangement.
3. Make strategic moves to arrange the numbers correctly.
4. Use hints when needed.
5. Complete the puzzle efficiently while tracking your time, moves, and score.

## 🕹️ How to Play

1. Visit the [Brain IQ 100 website](https://brainiqtester.vercel.app/).
2. Select your preferred game mode and difficulty.
3. Click **Play Now**, **Random Puzzle**, or **Daily Challenge**.
4. Arrange the numbers according to the target arrangement.
5. Use the available controls to undo, redo, pause, or request a hint.
6. Complete the puzzle and review your game progress.

## 🧩 Game Dashboard

The game interface displays useful information, including:

| Indicator | Purpose |
|---|---|
| Time | Tracks the time spent playing |
| Moves | Counts moves made during the puzzle |
| Score | Displays the current game score |
| Correct | Tracks correctly arranged numbers |
| Remaining | Shows numbers still to be arranged |
| Hints Left | Displays the remaining hints |
| Best Score | Shows the best score when available |
| Minimum Moves | Displays the minimum-move record when available |
